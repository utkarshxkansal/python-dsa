# Binary Trees

This folder contains binary-tree construction, traversal and problem-solving practice in Python.

## Existing fundamentals
- `introduction.ipynb` — creating a binary tree and connecting child nodes.
- `preorder.ipynb` — recursive preorder traversal.
- `Untitled.ipynb` — recursive inorder traversal.

## Problem solutions and traversal patterns
- `iterative_all_traversals.py` — preorder, inorder and postorder using one stack.
- `maximum_depth.py` — recursive maximum depth / height of a binary tree (LeetCode 104).
- `same_tree.py` — recursive structural and value comparison (LeetCode 100).

- `level_order_traversal.py` — breadth-first level order traversal using a queue (LeetCode 102).

## Conventions
- LeetCode-style solutions use `root.val`, `root.left`, and `root.right`.
- The notebooks retain the earlier practice convention using `node.data`.
- Each problem file contains a short explanation and complexity notes.
