# Linked Lists

Practice notebooks for three common linked-list variants.

## Folders

- `singly_linked_list/` — insertion and deletion operations.
- `doubly_linked_list/` — insertion, deletion, and array conversion.
- `circular_linked_list/` — circular-list insertion and deletion.

The notebooks preserve the original hands-on implementations. Review pointer updates carefully, especially at the head, tail, and single-node boundaries.
