# Stacks and Queues

This section contains implementations and practice notebooks for linear data structures.

## Folders

- `stack/` — stack implementations using arrays/lists, linked lists, and queues.
- `queue/` — queue basics, array and linked-list implementations, and queue-related problems.

## Key ideas to practise

- Stack: LIFO (last in, first out).
- Queue: FIFO (first in, first out).
- Check underflow, overflow, empty structures, and single-element cases.
