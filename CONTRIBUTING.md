# Contributing to Python DSA

This repository records hands-on learning and implementations of data structures and algorithms in Python. Suggestions and corrections are welcome.

## Guidelines

- Keep changes focused on one data structure, algorithm, or problem.
- Use descriptive filenames and preserve the existing folder layout unless a rename is intentional.
- Prefer readable implementations over unnecessary shortcuts.
- Add a short explanation of the approach and important invariants.
- Include example usage and expected output where useful.
- Test empty inputs, single-element cases, and boundary conditions.
- State time and space complexity when the implementation is ready.
- Do not commit virtual environments, notebook checkpoints, credentials, or unrelated generated files.

## Suggested notebook/code structure

1. Problem or concept statement
2. Approach and key observations
3. Implementation
4. Example walkthrough
5. Edge cases
6. Complexity analysis

## Workflow

1. Create a focused branch.
2. Make and test the change.
3. Explain what changed and how it was tested.
4. Open a pull request or record the improvement in the relevant learning notes.
