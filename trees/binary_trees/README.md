# Binary Trees

Binary-tree fundamentals, traversal patterns, and problem solutions in Python.

## Fundamentals and traversals

- `introduction.ipynb` — creating a binary tree and connecting child nodes.
- `preorder.ipynb` — recursive preorder traversal.
- `inorder.ipynb` — recursive inorder traversal.
- `level_order_practice.ipynb` — hands-on level-order traversal with a sample tree.
- `preorder_inorder_postorder_practice.ipynb` — all three traversals using a stack and state markers.
- `level_order_traversal.py` — breadth-first traversal using a queue (LeetCode 102).
- `iterative_all_traversals.py` — preorder, inorder, and postorder using one stack.

## Binary-tree problems

- `maximum_depth.py` — maximum depth / height (LeetCode 104).
- `same_tree.py` — compare structure and corresponding node values (LeetCode 100).

## Conventions

- LeetCode-style solutions use `root.val`, `root.left`, and `root.right`.
- Some original practice notebooks use `node.data`; these are preserved as part of the learning history.
- Recursive solutions should state their base case and account for the recursion stack.
